# TapeLog Coach: no-install AI trade review

Use this if you don't run an MCP server.

- **ChatGPT Custom GPT:** Explore GPTs, then Create, then Configure. Paste `instructions.md` into **Instructions**, turn on **Code Interpreter & Data Analysis**, and upload `../samples/SAMPLE_generic_60_trades.csv` as Knowledge if you want a demo.
- **Claude Project:** create a Project, paste `instructions.md` into **Project instructions**, then upload your CSV in a chat.
- **One-off chat (ChatGPT, Claude, Grok, Gemini):** paste `leak-analysis-prompt.md` and attach your CSV.

Educational and record-keeping only. Not investment advice. TapeLog is not a registered investment adviser.
